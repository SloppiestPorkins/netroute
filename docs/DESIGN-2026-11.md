# NetRoute design plan, November 2026

## Problem

The window feels heavy. At the default height, an app list showed about three apps,
because each row carried a title, a summary, a live-numbers strip and five controls.
The header carried six buttons. The same live data was shown in three places.

## What the research says

- **Keep the main action and status on the main screen; move detail behind a menu or
  toggle.** NordVPN's desktop and mobile redesigns, and VyprVPN 3.0, both removed clutter
  this way, and both report building the change from user interviews and usability tests.
  Those are vendor-reported outcomes, not independent studies.
- **Search and selection get prominent entry points.** NordVPN replaced a long server list
  with a search bar and suggestions.
- **Density is a choice.** Windows' own spacing guidance offers a standard and a compact
  density, and a compact list is the usual answer when a list holds many items. Windows
  Q&A reports that Windows 11's compact view does not shrink rows as much as Windows 10 did,
  so the row height needs setting explicitly rather than assumed.
- **Colour marks problems only.** Design-system guidance (Dynatrace, skills.sh) argues for
  a small colour budget, neutral for healthy states, and not relying on colour alone.

## Decisions

1. **One row per app:** icon, name, one status pill, a settings button. Nothing else.
2. **Per-app settings open from the row.** Change connection, why it's there, pause, remove.
   These were crowding the row and now live in one panel.
3. **Header:** Pause and Emergency Disable stay visible, plus Settings. Test connections,
   Check-up, All traffic and Updates move into one "More" menu, keeping their badges.
4. **Live data in one place.** The per-app numbers stay on the connection cards, and the
   All traffic overlay stays as the full view. The row strip is removed.
5. **Colour only for problems.** Healthy rows are neutral; the leak row is the only
   strong colour.
6. **Global settings in one panel.** Fallback behaviour is set in Settings; the per-app
   box follows it and says so.

## Phases

- **Phase 1, done:** app rows reduced to one line; per-app settings panel. Roughly twice
  as many apps fit on screen.
- **Phase 2:** move Test connections, Check-up, All traffic and Updates into a More menu;
  shrink the connection cards to one line each.
- **Phase 3:** remove the Live overlay's duplicate row layout and reuse the connection
  cards for the live numbers.
- **Phase 4:** check every panel at the 780 px minimum width and at 4K scaling.

## Not decided

- Whether to keep the Downloads/Gaming grouping or show one flat list with a connection
  column. The grouping is what makes a leak visible, so the default is to keep it.
